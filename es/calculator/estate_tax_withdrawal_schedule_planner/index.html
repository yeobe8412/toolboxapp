Estate Tax Withdrawal Schedule Planner

Este planificador simula cómo un programa de retiradas durante la vida puede modificar el tamaño de un patrimonio y su exposición modelizada al impuesto sobre sucesiones. Introduce un patrimonio inicial, una retirada anual, una tasa de crecimiento, un horizonte y una exclusión para observar el saldo final y la base potencialmente expuesta.

La herramienta no determina si una retirada, donación o transferencia es jurídicamente eficaz ni fiscalmente eficiente. Su función es mostrar la interacción matemática entre crecimiento y salidas periódicas para apoyar conversaciones de planificación y necesidades de liquidez.

Espacio publicitario

1. Introduce el patrimonio inicial

Usa el valor de los activos incluidos en el escenario al inicio del plan.

2. Define la retirada anual

Indica una cantidad constante que saldrá del patrimonio cada año.

3. Añade el crecimiento

La tasa se aplica al saldo restante después de la retirada anual.

4. Selecciona el horizonte

Elige cuántos años quieres simular.

5. Configura exclusión y tipo

Ajusta la exclusión disponible y la tasa para estimar la exposición fiscal del patrimonio final.

6. Compara escenarios

Prueba retiradas y crecimientos diferentes para ver cómo cambian el saldo y la exposición final.

Saldo del año siguiente = máx(0, saldo actual − retirada) × (1 + crecimiento) Base final expuesta = máx(0, patrimonio final − exclusión) Impuesto final modelizado = base final expuesta × tipo fiscal

Qué significa el resultado

El resultado principal es el patrimonio que queda al finalizar el horizonte después de las retiradas y el crecimiento supuesto.

No se modelizan impuestos sobre las propias retiradas, donaciones, cambios legislativos ni variaciones de la exclusión con el tiempo.

Datos: 20.000.000 USD iniciales, retirada anual de 250.000 USD, crecimiento del 4 % y 3 años.

Cálculo: año 1: (20.000.000 − 250.000) × 1,04 = 20.540.000 USD. El mismo proceso se repite durante los años siguientes.

Resultado: el saldo final se compara con la exclusión indicada para estimar una base potencialmente expuesta.

¿La retirada se aplica antes o después del crecimiento?

En este modelo se resta al inicio de cada periodo y después se aplica el crecimiento al saldo restante. Cambiar el momento de los flujos puede alterar el resultado.

¿Las retiradas reducen automáticamente el patrimonio gravable?

No necesariamente. Depende de qué ocurre con el dinero retirado y de las reglas de inclusión patrimonial. Aquí solo se reduce el saldo del modelo.

¿La exclusión cambia durante los años proyectados?

No. La herramienta usa una exclusión final constante introducida por el usuario para mantener el escenario transparente.

¿Qué ocurre si las retiradas superan el saldo?

El patrimonio se limita a cero; el modelo no permite saldos negativos.

¿Puedo usarla para planificar donaciones anuales?

Puedes modelizar salidas periódicas, pero una donación tiene reglas propias de gift tax y puede requerir otra herramienta para evaluar exclusiones y posibles impuestos.
