Calculadora de inventario de eBay

Estima cuántas unidades conviene tener disponibles para cubrir una demanda diaria esperada durante un plazo objetivo, añadiendo un stock de seguridad. También compara ese objetivo con el inventario actual y calcula cuántos días de demanda puede cubrir el stock existente. Es una herramienta de planificación sencilla, no un sistema de previsión de demanda.

1. Estima la demanda diaria
Usa un promedio reciente o una previsión que represente la velocidad de venta esperada.

2. Define la cobertura
Indica cuántos días quieres poder atender con el inventario objetivo.

3. Añade stock de seguridad
Reserva unidades extra para variaciones de demanda o retrasos.

4. Introduce el stock actual
Cuenta las unidades realmente disponibles para vender.

5. Revisa la reposición
La calculadora muestra cuántas unidades faltan para alcanzar el objetivo; si no faltan, el valor es cero.

Stock objetivo = Demanda diaria × Días de cobertura + Stock de seguridad Reposición sugerida = max(0, Stock objetivo − Inventario actual) Cobertura actual = Inventario actual / Demanda diaria

El modelo supone una demanda media constante durante el periodo y no incluye pedidos ya en tránsito salvo que los sumes al inventario disponible.

Qué significa el resultado

El resultado principal muestra las unidades que faltan para llevar el inventario actual hasta el objetivo definido.

Si la demanda es estacional o muy variable, prueba distintos escenarios y actualiza la media con frecuencia.

Datos: demanda de 8 unidades al día, cobertura objetivo de 21 días, stock de seguridad de 30 unidades y 120 unidades disponibles.

Cálculo: stock objetivo = 8 × 21 + 30 = 198. Reposición = 198 − 120 = 78 unidades. Cobertura actual = 120 / 8 = 15 días.

Resultado: faltarían 78 unidades para alcanzar el objetivo de inventario definido.

¿El stock de seguridad ya está incluido en los días de cobertura?

No. En este modelo se añade por separado al consumo previsto durante los días de cobertura.

¿Qué ocurre si tengo más stock que el objetivo?

La reposición sugerida será cero y el indicador de diferencia mostrará un superávit.

¿Puedo incluir inventario en tránsito?

Sí, pero debes decidir si lo consideras disponible para el horizonte analizado. Puedes sumarlo al inventario actual si su llegada está suficientemente asegurada.

¿Qué hago si la demanda diaria es cero?

El stock objetivo se limita al stock de seguridad y la cobertura en días no puede calcularse de forma significativa.

¿En qué se diferencia de una calculadora de punto de pedido?

Aquí defines días de cobertura y stock de seguridad para obtener un objetivo de existencias. El punto de pedido suele centrarse en demanda durante el plazo de reposición más stock de seguridad.
