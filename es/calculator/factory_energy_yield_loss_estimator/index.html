Estimador de pérdida de rendimiento en operaciones de energía de fábrica

Este estimador cuantifica la pérdida de rendimiento de un proceso a partir de las unidades totales y las unidades buenas. Además, distribuye el consumo energético del periodo de forma proporcional para obtener una referencia de la energía asociada a la producción no conforme.

El porcentaje de pérdida ayuda a seguir rechazos, merma o unidades que no llegan al criterio de salida seleccionado. La energía atribuida a pérdidas es una aproximación proporcional: no demuestra cuánta energía consumió físicamente cada unidad rechazada, pero permite construir una referencia consistente cuando no existe una medición más granular.

1. Introduce todas las unidades procesadas
Incluye las unidades producidas antes de separar conformes y no conformes.

2. Indica las unidades buenas
Usa el número que cumple el criterio de calidad definido para el periodo.

3. Añade la energía del mismo alcance
Introduce los kWh consumidos por el proceso o área durante ese mismo intervalo.

4. Interpreta pérdida y rendimiento
La pérdida porcentual y el rendimiento bueno son complementarios; juntos suman el 100 % cuando el total es mayor que cero.

5. Usa la energía perdida como referencia
Trátala como una atribución proporcional para priorizar análisis, no como una medición directa de cada rechazo.

Unidades perdidas = unidades totales − unidades buenas Pérdida de rendimiento (%) = unidades perdidas / unidades totales × 100 Rendimiento bueno (%) = unidades buenas / unidades totales × 100 Energía atribuida a pérdidas = energía total × (pérdida de rendimiento / 100)

La atribución energética supone que el consumo medio se reparte proporcionalmente entre unidades buenas y perdidas. Si el total es 0, los porcentajes se muestran como 0.

Qué significa el resultado

Una pérdida del 5 % significa que 5 de cada 100 unidades procesadas no se clasificaron como buenas según el criterio introducido.

Para estudiar el coste energético real de los rechazos puede ser necesario medir etapas de proceso y reprocesos por separado.

Datos:

  • 2.400 unidades totales
  • 2.280 unidades buenas
  • 1.680 kWh consumidos

Cálculo:

Unidades perdidas = 2.400 − 2.280 = 120

Pérdida = 120 / 2.400 × 100 = 5,00 %

Rendimiento bueno = 2.280 / 2.400 × 100 = 95,00 %

Energía atribuida = 1.680 × 0,05 = 84 kWh

Resultado: 5,00 % de pérdida

Interpretación: El periodo perdió 120 unidades respecto al total procesado y, con una asignación proporcional, 84 kWh quedan asociados a esa pérdida.

¿Una unidad retrabajada es una pérdida?

Depende del punto de medición y del criterio de “unidad buena”. Si el retrabajo todavía no cumple el criterio de salida, conviene no contarlo como bueno hasta que lo alcance.

¿La energía atribuida a pérdidas es energía realmente desperdiciada?

Es una estimación proporcional, no una medición física directa. Procesos con reprocesos, hornos, arranques o consumos fijos pueden repartir la energía de otra forma.

¿Puedo usar peso o toneladas en lugar de unidades?

La lógica funciona con cualquier base homogénea si “total” y “bueno” usan exactamente la misma unidad. No mezcles recuentos con masa o volumen dentro del mismo cálculo.

¿Qué significa una pérdida del 0 %?

Significa que las unidades buenas son iguales a las unidades totales introducidas. No implica por sí sola que no existan pérdidas de tiempo, velocidad o energía.

¿Cómo se relaciona con OEE?

La calidad es uno de los tres factores del OEE. Esta herramienta se centra en la pérdida de rendimiento y añade una referencia energética, mientras que OEE también incorpora disponibilidad y velocidad.
