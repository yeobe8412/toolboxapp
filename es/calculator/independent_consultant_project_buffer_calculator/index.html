Calculadora de margen de seguridad para proyectos de consultoría independiente

Esta calculadora añade un margen operativo a la estimación base de un proyecto de consultoría independiente. Parte de las horas de ejecución previstas, aplica un porcentaje de contingencia y suma, si procede, un bloque fijo para coordinación, revisiones o cierre. Así obtienes un total de horas planificadas que incorpora incertidumbre antes de comprometer una fecha o un presupuesto.

Resulta especialmente útil cuando el alcance está suficientemente definido para estimar el trabajo, pero todavía puede haber iteraciones, esperas del cliente o pequeños cambios. El margen no sustituye a una buena definición del alcance: simplemente permite reservar capacidad para variaciones razonables sin tratar cada desviación como una emergencia.

1. Estima el trabajo base
Introduce las horas que requeriría el alcance conocido sin añadir contingencia.

2. Elige un margen porcentual
Añade un porcentaje que crezca con el tamaño del proyecto para cubrir variaciones proporcionales.

3. Añade margen fijo si hace falta
Reserva horas concretas para coordinación, revisión final, traspaso o tareas similares.

4. Comprueba el total
Usa las horas planificadas para contrastar agenda, presupuesto y fecha de entrega.

5. Ajusta según el riesgo
Prueba escenarios con distinto margen cuando el alcance o las dependencias aún sean inciertos.

Horas planificadas = H_base × (1 + B/100) + H_fijas

H_base: horas estimadas para ejecutar el alcance conocido.

B: porcentaje de contingencia que se aplica sobre las horas base.

H_fijas: horas adicionales que no dependen del tamaño del proyecto.

Supuestos: El modelo trata el margen como reserva de planificación. No presupone que todas las horas de contingencia vayan a consumirse.

Qué significa el resultado

El total muestra cuánta capacidad conviene bloquear en la agenda con los supuestos elegidos. La diferencia frente a las horas base es el margen disponible para absorber desviaciones.

Si el alcance cambia de forma material, conviene rehacer la estimación base en lugar de seguir aumentando el margen.

Datos:

  • 80 h base
  • 15 % de margen porcentual
  • 6 h de margen fijo

Cálculo:
Margen porcentual = 80 × 0,15 = 12 h
Margen total = 12 + 6 = 18 h
Horas planificadas = 80 + 18 = 98 h

Resultado: 98 horas planificadas.

Interpretación: La agenda reserva 18 horas adicionales sobre las 80 estimadas inicialmente, sin asumir que deban utilizarse por completo.

¿El margen debe facturarse siempre al cliente?

No necesariamente. Esta calculadora mide reserva de capacidad; la forma de presupuestar o facturar esa reserva depende del contrato, del modelo de precios y del alcance acordado.

¿Cuándo conviene usar margen fijo y cuándo porcentual?

El porcentaje funciona bien para incertidumbres que crecen con el tamaño del proyecto. El margen fijo encaja mejor con tareas previsibles, como una sesión de cierre o un bloque concreto de revisiones.

¿Puedo poner un margen del 0 %?

Sí. En ese caso el total solo añadirá el margen fijo, si existe. Es útil para comparar una estimación sin contingencia con otra más conservadora.

¿Qué ocurre si aparecen cambios de alcance importantes?

Un cambio material debería revisarse como nuevo trabajo o como una nueva estimación. El margen está pensado para variaciones razonables, no para cubrir indefinidamente un alcance distinto.

¿En qué se diferencia de la capacidad facturable?

El buffer se aplica a un proyecto concreto para reservar tiempo adicional. La capacidad facturable estima cuánto trabajo cobrable puede sostener tu calendario durante un periodo más amplio.
