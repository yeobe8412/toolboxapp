Calculadora de contexto de Claude

Comprueba cuánto espacio de contexto consume una solicitud de Claude antes de enviarla. Suma sistema, historial, documentos, mensaje actual y la salida máxima que quieres reservar, y compáralos con el límite de contexto que corresponda a tu modelo y configuración. El límite es configurable porque la capacidad puede variar entre modelos, proveedores y modalidades. La herramienta ayuda a evitar diseños que se acercan demasiado al máximo y a decidir si conviene resumir conversaciones, reducir documentos o bajar la reserva de salida.

5. Comprueba el margen
Si superas el 100 %, reduce entrada o salida antes de enviar la solicitud.

entrada = sistema + historial + documentos + mensaje actual
ocupación = (entrada + salida reservada) / límite × 100
margen = límite − entrada − salida reservada

Qué significa el resultado

El porcentaje muestra qué parte de la ventana has comprometido si la respuesta llega hasta la salida máxima reservada.

Los límites y posibles reglas de contexto largo dependen del modelo y del acceso. Introduce el límite aplicable a tu caso.

Datos: límite 200.000; sistema 1.000, historial 25.000, documentos 70.000, mensaje 2.000 y salida 8.000.

Cálculo: 106.000 / 200.000 = 53 %.

Resultado: 94.000 tokens de margen.

¿La salida cuenta dentro del contexto?

Debes reservar capacidad para la salida cuando planificas la solicitud. Esta calculadora la incluye para mostrar el espacio total comprometido.

¿Qué límite de contexto debo usar?

El que indique la documentación vigente para tu modelo, proveedor y modalidad. No presupongas que todos los modelos tienen el mismo límite.

¿Qué ocurre si el resultado supera el 100 %?

La solicitud planificada no cabe con esos supuestos. Reduce historial, documentos, mensaje o salida máxima.

¿La caché de prompts libera espacio de contexto?

No necesariamente. El contenido cacheado puede tener un tratamiento de facturación distinto, pero sigue siendo relevante para las reglas de contexto aplicables.

¿Cómo reduzco un historial largo?

Puedes resumir turnos antiguos, conservar solo hechos necesarios o recuperar información bajo demanda, siempre comprobando que no pierdes contexto crítico.
