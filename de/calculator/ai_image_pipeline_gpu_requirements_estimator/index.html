GPU-Bedarfsrechner für KI-Bildpipelines

Der GPU-Bedarfsrechner für KI-Bildpipelines übersetzt Auftragsvolumen und gemessene GPU-Zeit pro Task in eine erforderliche GPU-Anzahl. Dabei wird die geplante nutzbare Auslastung berücksichtigt, damit die Rechnung nicht von permanenten 100 % Auslastung ausgeht.

Zusätzlich kann eine Reserve für Lastspitzen, Wartung oder Failover eingeplant werden. Das Ergebnis eignet sich zur Größenordnung einer Flotte; Speicherbedarf, Modellparallelität, CPU-Engpässe und Batch-Effekte müssen separat geprüft werden.

  1. Zieldurchsatz festlegen. Geben Sie die nachhaltig benötigten Bild-Tasks pro Stunde an.
  2. GPU-Zeit pro Task messen. Verwenden Sie einen repräsentativen Durchschnitt unter der geplanten Modell- und Auflösungskonfiguration.
  3. Zielauslastung setzen. Werte unter 100 % lassen Raum für Schwankungen und Overhead.
  4. Reserve ergänzen. Planen Sie optional zusätzliche Kapazität für Peaks oder Ausfälle ein.
  5. Auf ganze GPUs aufrunden. Die angezeigte Hauptzahl ist die praktikable Mindestzahl ganzer GPUs.
Rohbedarf = Tasks/h × GPU-Sekunden/Task / 3600
Bedarf bei Zielauslastung = Rohbedarf / (Auslastung/100)
Bedarf inkl. Reserve = Bedarf × (1 + Reserve/100)

Die Formel behandelt die GPU-Sekunden pro Task als gemessenen Ressourcenverbrauch. Batchgrößen oder parallele Streams können diesen Wert verändern und sollten in einer realistischen Messung bereits enthalten sein.

Was das Ergebnis bedeutet

Die Hauptzahl ist die auf ganze Geräte aufgerundete GPU-Anzahl, die das Zielvolumen unter den angegebenen Annahmen tragen soll.

Prüfen Sie zusätzlich VRAM, Modellgröße und Datenpipeline, bevor Sie Hardware verbindlich dimensionieren.

Gegeben: 1.200 Tasks/h, 9,5 GPU-s/Task, 75 % Zielauslastung und 20 % Reserve.

Berechnung: Rohbedarf = 1.200 × 9,5 / 3.600 = 3,17 GPUs. Bei 75 % Auslastung: 3,17 / 0,75 = 4,22. Mit Reserve: 4,22 × 1,20 = 5,07.

Ergebnis: Aufgerundet werden 6 GPUs eingeplant.

Warum darf die Zielauslastung nicht 0 % sein?

Bei 0 % könnte keine Arbeit verarbeitet werden und die Division wäre nicht definiert. Verwenden Sie einen realistischen Wert größer als 0 und höchstens 100 %.

Soll ich die mittlere oder maximale GPU-Zeit verwenden?

Für Basisplanung eignet sich ein repräsentativer Durchschnitt. Bei harten Durchsatzgarantien sollten Sie zusätzlich ein konservatives Szenario mit höherer GPU-Zeit rechnen.

Berücksichtigt der Rechner VRAM?

Nein. Ausreichender VRAM ist eine separate Voraussetzung und kann den nutzbaren GPU-Typ oder die Parallelität begrenzen.

Wie wirkt sich Batching aus?

Batching kann die effektiven GPU-Sekunden pro Task senken oder erhöhen. Messen Sie daher möglichst mit der Batchgröße, die später produktiv eingesetzt wird.

Ist die Reserve dasselbe wie niedrigere Zielauslastung?

Beides schafft Puffer, aber an unterschiedlichen Stellen. Die Zielauslastung modelliert den dauerhaften Betriebspunkt, die Reserve zusätzliche Flottenkapazität darüber hinaus.
