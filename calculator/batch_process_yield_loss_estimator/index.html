Batch Process Yield Loss Estimator

The Batch Process Yield Loss Estimator quantifies how much material or product is lost between gross batch output and accepted good output. It reports both the loss quantity and the loss percentage, making it easier to compare batches of different sizes.

The tool is useful for batch operations that track rejects, scrap, off-spec material, spills, trim, or other losses after a production step. Enter the total amount produced and the good amount retained. The result can support loss trending, cost investigations, and process-improvement reviews, but it does not identify the root cause of the loss; that requires process and quality data from the operation itself.

1. Enter gross batch output
Use the total quantity produced before removing nonconforming or otherwise lost output.

2. Enter accepted good output
Use the quantity that remains usable under your normal acceptance rules.

3. Keep units consistent
Both quantities must use the same unit, such as pieces, kilograms, or liters.

4. Review the loss rate
The headline result shows lost output as a percentage of total output.

5. Use supporting values
Check lost quantity, yield, and loss per 1,000 for reporting and comparison.

Yield loss rate = (Total output − Good output) ÷ Total output × 100

Total output = all output produced in the batch
Good output = accepted usable output from the same batch

Assumption: The calculation treats the difference between total and good output as loss; it does not separate scrap, rework, or measurement loss unless your data does.

What the result means

Use the result as an estimate based on the values and boundaries you entered. Compare like-for-like periods and units when tracking changes.

Actual process results can differ because of downtime, product mix, measurement methods, operating conditions, and quality rules.

Given:
Total batch output = 12,500 kg
Good accepted output = 11,875 kg

Calculation:
Loss = 12,500 − 11,875 = 625 kg; loss rate = 625 ÷ 12,500 × 100 = 5.0%; good yield = 95.0%; loss per 1,000 = 50.

Result:
5.00% yield loss

The batch loses 625 kg, equivalent to 50 kg of loss for every 1,000 kg of gross output.

Can I use weight instead of pieces?

Yes. Any unit works as long as total output and good output use the same unit and represent the same production boundary.

Should rework be treated as loss?

It depends on your reporting rule. If rework eventually becomes accepted output, you may count it as good, but track rework separately if it creates meaningful cost or capacity loss.

What does loss per 1,000 mean?

It scales the loss ratio to a base of 1,000 units, which can make comparisons easier when batch sizes differ.

What if good output is larger than total output?

That is inconsistent input data, so the calculator rejects it. Check unit conversions, batch boundaries, and data timing.

How is yield loss different from OEE quality?

They use the same good-versus-total concept, but OEE quality is one factor inside a broader equipment-effectiveness metric while yield loss focuses only on output loss.
