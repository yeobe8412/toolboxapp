Leadership Pipeline Capacity Gap Calculator

The Leadership Pipeline Capacity Gap Calculator estimates whether the succession pipeline contains enough ready or near-ready candidates to cover critical leadership roles. It multiplies the number of critical roles by the desired number of successors per role, then compares that target with ready-now successors plus candidates expected to become ready within the planning horizon. The remaining shortfall is reported as the capacity gap.

Talent and workforce planning teams can use this measure to test succession coverage under different readiness assumptions. A gap can support decisions about development intensity, external recruiting, role redesign, or risk mitigation. The calculator treats candidates as interchangeable units for aggregate planning; real succession decisions still depend on role fit, location, mobility, timing, performance, and whether one candidate is being counted against multiple roles.

1. Define the measurement scope
Use one consistent employee population and time period. For this calculator, the key inputs are Critical leadership roles, Desired successors per role, Ready-now successors, and Candidates expected to become ready in horizon.

2. Enter the inputs
Replace the default values with figures from the same cohort or planning scenario. Keep percentages on a 0–100 scale and monetary inputs in U.S. dollars.

3. Check the assumptions
Make sure counts refer to people or capacity units only once and that annual, monthly, or program-period figures are not mixed.

4. Review the result
The headline result updates automatically as inputs change. Use the breakdown to see the intermediate values that drive the estimate.

5. Test another scenario
Change one assumption at a time to see which input has the largest effect. Use Reset to return to the starting example values.

Leadership pipeline capacity gap = max[(Critical roles × Desired successors per role) − (Ready-now successors + Candidates expected to become ready), 0]

Where:

Critical roles: leadership positions included in succession planning.

Desired successors per role: target depth of qualified coverage for each role.

Ready-now successors: candidates currently assessed as able to step into a relevant role.

Candidates expected to become ready: near-ready candidates projected to meet readiness criteria within the chosen horizon.

What the result means

A positive gap shows how many additional successor-capacity units are needed to meet the stated coverage target.

Avoid double-counting the same person across several roles unless your planning method explicitly allows shared successor coverage.

Given

  • Critical leadership roles: 50
  • Desired successors per role: 1.4
  • Ready-now successors: 39
  • Expected to become ready: 21

Calculation
Target capacity = 50 × 1.4 = 70 successors
Available pipeline = 39 + 21 = 60 candidates
Gap = 70 − 60 = 10 candidates

Result
The aggregate pipeline is short by 10 candidates and covers about 85.7% of the target succession capacity.

Why allow more than one successor per role?

Many succession plans target pipeline depth rather than one-for-one coverage. A value such as 1.5 can represent a portfolio-level goal where some roles have one successor and others have two.

Should near-ready candidates be included?

Include them only when the planning horizon is long enough and there is a credible path to readiness. For immediate vacancy risk, use ready-now candidates only.

What if one candidate could succeed several roles?

The simple aggregate model can overstate capacity if the same person is counted repeatedly. For precise role-by-role risk, use a succession matrix that tracks candidate overlap.

Why does the main gap never become negative?

A shortfall bottoms out at zero. When the available pipeline exceeds the target, the excess is shown separately as surplus candidates.

Is 100% pipeline coverage enough?

It meets the numeric target you entered, but it does not guarantee fit for every specific role. Readiness quality, diversity of experience, mobility, and concentration risk still need review.
