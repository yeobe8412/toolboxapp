Gaming Stream Prize Pool Split Calculator

The Gaming Stream Prize Pool Split Calculator divides a stream-based competition or community prize budget between a headline winner, a runner-up, and a configurable number of additional winners. It is designed for creator tournaments, viewer challenges, sponsored stream events, and similar formats where organizers want a clear payout structure without building a full spreadsheet.

The first- and second-place shares are entered directly as percentages. Whatever remains is divided evenly across the additional winners. The calculator reports each payout and checks that the top shares leave a valid remainder, making it easy to test how concentrated or broad the reward distribution should be.

Winner payout = Prize pool × Winner % / 100
Runner-up payout = Prize pool × Runner-up % / 100
Remaining pool = Prize pool × [1 − (Winner % + Runner-up %) / 100]
Each additional payout = Remaining pool / Additional winners

Where:

  • Prize pool = total amount available for this stream competition.
  • Winner % and Runner-up % = direct percentage awards.
  • Additional winners = number of equal-share recipients below the top two.

Assumptions: The remaining prize pool is split evenly among all additional winners. Platform fees, withholding, and team splits are not included.

What the result means

The main result is the headline winner payout, while the breakdown shows the rest of the prize budget.

Use net or gross prize amounts consistently, especially if sponsor fees or platform deductions are handled outside the payout pool.

Given:

  • $25,000 prize pool
  • Winner = 50%
  • Runner-up = 25%
  • 5 additional winners

Calculation:
Winner = $12,500. Runner-up = $6,250. Remaining pool = $6,250. Each additional winner = $6,250 / 5 = $1,250.

Result:
Winner payout = $12,500.

Interpretation:
Half the pool goes to the winner, one quarter to the runner-up, and the final quarter is shared equally by five additional winners.

What if the winner and runner-up shares add to more than 100%?

The calculator rejects the combination because it would over-allocate the prize pool. Reduce one or both percentages.

Can there be only one additional winner?

Yes. Set additional winners to 1 and that person receives the full remainder after the top two payouts.

Does this work for teams instead of individuals?

Yes. Each “winner” can represent a team. Any internal team split would need to be handled separately.

Should sponsor bonuses be included?

Include them only if they are part of the same payout pool. Separate fixed bonuses are easier to track outside this split.

How is this different from the esports tournament prize splitter?

This model is optimized for a top-two-plus-equal-remainder stream format, while the tournament version uses explicit top-three shares and a configurable number of paid placements.
